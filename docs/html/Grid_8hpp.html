Detailed Description

Local grid owned by one MPI rank, with ghost-row communication.

The global nxn grid is decomposed by rows among size MPI processes. Each rank owns a contiguous block of rows [row_start, row_end] of the global grid, plus one ghost row above and one below for neighbour data.

Memory layout of U_ (local storage): 

*   row 0 -> ghost row from rank-1  (or unused if rank==0)
*   row 1..local_rows -> actual owned rows
*   row local_rows+1 -> ghost row from rank+1  (or unused if rank==size-1)
