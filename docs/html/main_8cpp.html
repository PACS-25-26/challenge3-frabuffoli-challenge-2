Detailed Description

Entry point for the parallel Laplace solver.

Reads setup.json and BC.json from the current working directory, constructs the MPI-distributed grid, runs the chosen solver, exports the VTK solution, and logs convergence / timing / L2 error.

Typical invocation (via run.sh):

mpirun -np 4 laplace-solver
