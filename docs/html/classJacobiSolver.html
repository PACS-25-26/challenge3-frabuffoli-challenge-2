void JacobiSolver::solve ( )
overridevirtual

Run the Jacobi iteration until convergence or max iterations.

Algorithm:

  1. exchangeGhostRows() [MPI_Sendrecv]
  2. Update U_new in parallel [#pragma omp parallel for]
  3. Compute local error [omp reduction]
  4. MPI_Allreduce to get global error
  5. Swap U and U_new
  6. Re-apply non-Dirichlet BCs
  7. Check convergence
