Gather the distributed solution and write a VTK file.

Each rank sends its owned rows (rows 1..localRows of U_, excluding ghost rows) to rank 0 via MPI_Gather. Rank 0 then reconstructs the full nxn matrix and calls writeVTK().

Parameters
gridThe local distributed grid.
filenameBase filename (without extension), e.g. "solution". The file is written as outputDir/filename.vtk.
