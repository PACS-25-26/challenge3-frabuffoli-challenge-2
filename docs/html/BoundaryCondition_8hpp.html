Detailed Description

Boundary condition descriptor for the Laplace solver.

Supports Dirichlet, Neumann and Robin conditions on each of the four sides of the unit-square domain, loaded from a JSON file.

BC.json expected format:

{
"top" : { "type": "dirichlet", "expr": "0.0" },
"bottom" : { "type": "dirichlet", "expr": "0.0" },
"left" : { "type": "dirichlet", "expr": "0.0" },
"right" : { "type": "dirichlet", "expr": "0.0" }
}

For Robin conditions an additional alpha key must be provided.
